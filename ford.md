`rabe` (nea**r**-omnigenous, **a**symptotic **b**ootstrap **e**xpressions)
computes bootstrap current estimates for near omnigenous stellarators.

See the [README](https://github.com/itpplasma/rabe#readme) for the physics
background, and the module list in the sidebar for the API documentation.

[Performance benchmarks history](dev/bench/) is published separately from
continuous integration.
